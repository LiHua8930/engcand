英文候选助手

用中文输入法、偶尔要打英文？切到英文模式打字时，光标旁自动弹出英文单词 / 短语候选，按 1-9 一键选词，不用再猜拼写。

约 4.8 万单词 2 千余常用短语 5 万词对联想 不抢焦点 · 不联网 无需管理员权限
安装与启动 基本用法 快捷键 托盘菜单 设置项 自检 常见问题 数据与许可

1安装与启动

在项目根目录 english-cand\ 打开 PowerShell，依次执行：

  1. 构建程序：运行 build.ps1，生成 dist\app\EngCand.exe 并自动复制词典到 dist\app\data\。
    也可以直接双击项目里的 build.ps1（右键 → 使用 PowerShell 运行）。
  2. 安装快捷方式：运行 install.ps1，在桌面创建「英文候选助手」快捷方式；加 -AutoStart 可设置开机启动。
  3. 启动：双击桌面「英文候选助手」，或双击项目根目录的 启动.bat。
    程序常驻系统托盘（任务栏右下角，图标可能在 ^ 隐藏区里）。
# 在 english-cand 目录下
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
# 可选：设置开机启动
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -AutoStart
# 直接运行（不装快捷方式）
.\dist\app\EngCand.exe

注意 EngCand.exe 必须和 data\ 目录放在一起；单独拷走 exe 会没有词典、不弹候选。

2基本用法

  1. 用搜狗拼音切到 英文模式（按 Shift 或点状态栏「中/英」），正常打字。
  2. 输入 2 个字母以上，候选窗在光标附近出现（默认最多 8 条）。
  3. 按 1~9 选择候选，当前输入的字母会替换成完整单词 / 短语；也可以 鼠标点击 候选。
  4. 按 Esc 关闭；继续打字会实时刷新候选。
输入 tha → 1thank 2that 3than 4thanks 5thank you …

中文组词时不会弹窗（自动识别搜狗组词窗口）；英文模式下才弹。程序不修改输入法状态、不联网。

3快捷键

快捷键作用
1 ~ 9候选窗出现时选词（含小键盘；候选窗不可见时不影响正常输入）
Esc关闭候选窗
Ctrl+Alt+E启用 / 暂停英文候选（全局开关）
Ctrl+Alt+D显示状态气泡：词典数量、当前中/英判断、搜狗识别状态

热键是全局注册的；若被其它程序占用会静默失败，此时可在托盘菜单里完成同样的操作。

5设置项

设置默认说明
候选数量81~9 条，对应数字键 1-9

6自检

不需要打开界面即可验证词典与查询是否正常：

cd dist\app
.\EngCand.exe --selftest
echo $LASTEXITCODE   # 0 = 通过，1 = 失败

结果写入 exe 同目录的 selftest.log 和用户数据目录（默认 %APPDATA%\EngCand）下的 selftest.log；可用 --userdir=<目录> 覆盖用户数据目录（便携/测试用）。

ready = True
words = 48266  phrases = 1945
query[th] => the{W,999979} | that{W,999896} | ...
RESULT: PASS

7常见问题

打了英文，候选不弹？
① 确认输入法是英文模式（中文组词时故意不弹）；② 托盘菜单「启用」是否勾选；③ 模式是否被设为「强制中文」；④ 是否已输入 ≥2 个字母；⑤ 以管理员权限运行的窗口收不到普通权限的键盘钩子（Windows 限制）；⑥ 用 --selftest 确认词典已加载。
数字键选词后文本没变化 / 重复？
选词依赖「退格 + SendInput 注入」，个别编辑器 / 游戏 / 远程桌面不兼容。可先在记事本里验证；确认候选窗可见时数字键才会被接管。
快捷键没反应？
多半被其它程序（截图/录屏/输入法工具）占用。程序会静默失败，可在托盘菜单完成同样操作，日志里会有记录。
托盘图标找不到？
点任务栏右下角 ^ 展开隐藏图标，或把图标拖到任务栏固定。
启动提示「已经在运行」？
程序是单实例的，看托盘图标即可；要重启先在托盘菜单「退出」。
怎么开机自启 / 怎么卸载？
安装：install.ps1 -AutoStart；卸载：uninstall.ps1（加 -PurgeData 会同时删除 %APPDATA%\EngCand 里的配置、日志和学习记录）。

8数据来源与许可

运行时词典：words.tsv（48,267 词）、phrases.tsv（2,240 条短语）、word_bigrams.tsv（50,000 词对），位于 dist\app\data\，由项目 data\ 目录生成。

原始语料包括 FrequencyWords（OpenSubtitles，CC BY-SA 4.0）、google-10000-english、Peter Norvig 的 n-gram 统计、2ndLA 公开短语表（CC BY-SA 4.0）、baiango 习语表（The Unlicense）、自整理高频短语（本项目原创）等。

具体来源 URL、抓取方式与许可证见项目内 data\raw\README.md；词典版权归各上游项目所有。
